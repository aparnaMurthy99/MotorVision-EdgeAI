# Models – AI Model Development and Deployment

## Overview

This folder contains the trained and optimized machine learning models developed for the MotorVision-EdgeAI system.

## Model Architecture

- YOLOv8n – Object detection and motor component localization
- MobileNetV3 – Motor health-status classification

## Model Development
- Dataset preparation and organization
- Model training and validation
- Model evaluation
- TensorFlow Lite conversion
- INT8 quantization for embedded deployment

## Deployment Target

- Renesas RA8P1 Titan Mini
- TensorFlow Lite Micro
- Embedded Edge AI processing
