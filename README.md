# MotorVision-EdgeAI

## Embedded Edge AI for Motor Inspection and Health Monitoring

An intelligent vision-based motor inspection system using:

- ESP32-S3 with OV3660 camera
- YOLO for object detection and view validation
- OpenCV for image processing and geometrical inspection
- MobileNetV3 for motor health-status classification
- Renesas RA8P1 Titan Mini with RT-Thread for on-device Edge AI inference
